# Лаба 02. Топ клієнтів за виручкою

Типовий дашборд фінансів / CRM: «топ-20 клієнтів за місяць».

**Антипатерн:** корельований підзапит у `SELECT` — для кожного клієнта окремий прохід по `orders`.

**Оптимізація:** спочатку агрегація `orders` за місяць, потім `JOIN` лише на топ клієнтів. Частковий індекс `(created_at, customer_id) WHERE status IN ('paid', 'shipped')`.
