# Лаба 08. Місячний звіт продажів по категоріях

Типовий запит аналітики / 1С-інтеграції / Excel-вигрузки.

**Антипатерн:** `DATE(created_at) = ...` або `created_at::date` — функція на колонці вимикає індекс. Плюс `SELECT *` і зайві JOIN.

**Оптимізація:** діапазон по «голій» колонці `created_at` і попередня агрегація позицій, без `count(DISTINCT)`.
